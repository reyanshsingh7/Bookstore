# 📚 Bookstore Website

A frontend-only bookstore website developed as part of the **AKTU Web Development Lab Practical**. The project focuses on designing a clean, visually appealing, and user-friendly interface for an online bookstore.

## 🌐 Project Overview

This project demonstrates the fundamentals of frontend web development through a collection of static webpages representing an online bookstore. It focuses on website layout, styling, page structure, and navigation.

The website is developed for academic and practical learning purposes.

## ✨ Features

- Clean and user-friendly website interface
- Bookstore-themed webpage design
- Static frontend webpages
- Organized content and page layouts
- Basic website navigation
- Responsive styling (where implemented)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and page layouts
- **JavaScript** – Frontend scripting (if used)

## 🚀 How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/your-repository-name.git
   ```

2. Open the downloaded project folder.
3. Locate the main HTML file (`index.html`).
4. Open it in any modern web browser.

No backend setup or database configuration is required.

## ⚠️ Project Limitations

This is a **static frontend-only project**.

- No backend integration.
- No database connectivity or persistent data storage.
- Forms and input fields do not process or retain submitted information.
- No functional purchasing, checkout, or order management system.

The project primarily demonstrates frontend webpage design and development.
